# Age of Kumasi

A text-based strategy game inspired by Age of Empires II, reimagined through
Ghanaian civilizations.

## Play

```bash
python3 src/main.py
```

## Civilizations

- **Ashanti** — Gold mining bonus, Odwira Priest unique unit
- **Dagbon** — Building cost reduction, Lunsi Drummer reveals enemies
- **Ga** — Fishing bonus, Homowo Dancer terrifies foes
- **Ewe** — Unit speed bonus, Agbadza Dancer disrupts formations
- **Mamprusi** — Faster age advancement, Gatekeeper guards progression
- **Fante** — Naval bonus, Asafo Captain inspires troops

## Commands

| Command | Description |
|---------|-------------|
| `status` | Full empire status |
| `help` | List all commands |
| `build <building>` | Construct a building |
| `train <unit> [n]` | Train units |
| `gather <resource>` | Gather resources |
| `advance` | Advance to next age |
| `list units` | Show available units |
| `list buildings` | Show available buildings |
| `end` | End your turn |

## Ages

1. **Age of Settlement** — Village founding, basic units
2. **Age of Gold** — Trade, archers, cavalry
3. **Age of the Stool** — Palace, gunpowder, elite infantry
4. **Age of Resistance** — Siege, war drums, final conflict

## Resources

- **Food** — Farming, fishing (yam, plantain, fish)
- **Wood** — Forest timber (buildings, ships)
- **Gold** — Gold Coast mining (units, upgrades, age advancement)
- **Kola** — Trans-Saharan trade good (defense, special tech)
